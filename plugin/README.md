**App Tabs**

Turn a list of web apps into top-bar tabs of the Unraid GUI. Each tab embeds the app in an iframe, or opens it in a new browser tab, and the address can use [HOST] for whatever hostname you opened Unraid with. A tab can also be a live console for a Docker container (a shell or a tmux session), shown through Unraid's own terminal server behind your Unraid login. Configure it under Settings, Utilities, App Tabs.
